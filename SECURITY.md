# Security Policy

## Reporting a vulnerability

Do not open a public GitHub issue for security reports.

Use [GitHub's private vulnerability reporting](https://github.com/oleedv/RoyalBattalionWebpage/security/advisories/new) instead. Include:

- a description of the issue
- steps to reproduce
- what an attacker could do with it

You should get an acknowledgement, and a fix will be worked on before any public disclosure.

## Scope

This repository is the Royal Battalion website and API. The production site is [royalbattalion.xyz](https://royalbattalion.xyz).
